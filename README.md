# Your Pocket Gym — Version 1

A free, mobile-first workout/PWA prototype.

## Run it
Open `index.html` in a browser for a local demo.

## Put it on your iPhone for free
The easiest free route is to upload these files to a GitHub repository and enable GitHub Pages. Open the resulting Pages URL in Safari on your iPhone, tap Share → Add to Home Screen.

## What is included
- Mobile-first UI
- 3-day Push/Pull/Legs starter program
- Set, weight, and rep logging
- Rest timer
- Local workout history via localStorage
- Basic adaptive load suggestion
- Progress dashboard
- Profile/settings
- Prototype coach chat
